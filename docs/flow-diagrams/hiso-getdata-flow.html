Two branches worth knowing

The diagram above is drawn as the "everything succeeds" path — these are the forks it can take.

Gate

Dynamic-mode gate

Only IsDynamic=true and formInstanceOperationMode=="N" runs the real pipeline above. Every other combination (static mode, parked/resumed forms) is a genuine empty stub in the original legacy system too — reproduced as such, not a gap this project introduced.

Conditional

AWS / Aspose attachment branch

Only 6 procedures ever take this fork (attachments, incoming/outgoing letters, lab & radiology reports). It only fires when the practice has AWS document storage enabled — checked live via CheckAwsIsEnabledAsync against that practice's own DB, not a global switch.
