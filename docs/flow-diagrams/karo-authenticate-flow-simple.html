Socho ek school hai. Tum gate pe apna ID card aur password dikhate ho. Guard tumhara card leke ek bade office (jahan sab schools ka record rakha hai) mein check karta hai ke "yeh bacha kis school ka hai, aur uska school kis building mein hai". Phir woh building ke apne register mein check karta hai ke tumhara password sahi hai ya nahi. Agar sahi hai, tumhe ek "entry pass" (token) mil jata hai jo thodi der ke liye valid hota hai.

Do zaroori baatein

Nayi cheez

Address Book (Tenant Registry) se pata chalta hai konsa computer

Pehle system har clinic ka computer-address seedha apni settings file mein likha rakhta tha — matlab har naye clinic ke liye file mein tabdeeli karni parti thi. Ab ek "Address Book" (Tenant Registry) hai jahan sab clinics ka record hai — nayi clinic add karne ke liye sirf ek naya register-entry chahiye, koi file change nahi.

Zaroori farq

Ek hi clinic number, do alag jagah ho sakta hai

Kabhi kabhi ek hi clinic number (jaise 901) do alag computers pe hota hai — jaise ek "test" wala aur ek "asal" wala. Address Book mein clinic number ke sath ek chhota sa extra code bhi dekha jata hai (jaisa visit number ke andar chhupa hota hai), taake sahi computer hi milay, confuse na ho.
